# code

This is where we build during class. The news aggregator app lives here.

Early in the session I'll ask Claude to install the skills below into this folder, under `code/.claude/skills/`, so they only apply to this project. If you're following along, open Claude Code in this folder and ask it to do the same.

## Skills we install

| Skill | What it does | Link |
|---|---|---|
| grill-me | Interviews you until the plan holds up | https://github.com/mattpocock/skills |
| superpowers | A full workflow: brainstorm, plan, test first, review | https://github.com/obra/superpowers |
| impeccable | Design vocabulary and checks against generic AI-looking UI | https://impeccable.style |
| be-ambitious | Turns a task into a bigger plan and a more demanding prompt | https://github.com/robonuggets/be-ambitious |

Each repo's README has its own install steps. be-ambitious, for example, installs into a single project like this (run from this folder):

```
git clone https://github.com/robonuggets/be-ambitious .claude/skills/be-ambitious
```
