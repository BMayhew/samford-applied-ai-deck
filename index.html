How it works

The agent loop

A chatbot answers once. An agent keeps going: it reads, acts, checks what happened, and tries again.

1

Your prompt, project files, CLAUDE.md

2

Plan

Decide the next step toward the goal

3

4

Check

Read the output, test results, errors

Repeat until done, or until it needs you

This is the slide everything else hangs on. Most of you have used ChatGPT: you ask, it answers, you copy and paste. Claude Code runs this loop on its own. It reads files, makes a change, runs the tests, sees the failure, and fixes it. Your job shifts from typing code to steering the loop and checking the result.

Context: what Claude can see

Claude only knows what's in front of it. Better context gets you better code, faster.

CLAUDE.md

Project memory loaded every session: the stack, how to run tests, rules like "use TypeScript."

The working set

Files it reads, command output, your chat, and any docs or screenshots you hand it.

The window fills up

Same tools, different bar. The news aggregator we built is on the left side of this scale. If a company sold it, you'd need to think about secrets, auth, rate limits, legal use of the feeds, and a lot more testing. AI makes it fast to build, so the judgment about how much quality you need is on you. Keys go in .env and stay out of git and off the screen at every level.

Felix works on Claude at Anthropic. His point: most of us ask these models for far less than they can do. He breaks ambition into speed, altitude, depth, and range.
